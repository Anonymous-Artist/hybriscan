HybriScan

A Category-Aware, Weighted Heuristic Web Vulnerability Scanner with Adaptive Threshold Optimisation

Dishant P. Suthar • Udbodh V. Solanki

Abstract

HybriScan is a lightweight research-oriented web vulnerability scanner focused on reducing false positives through structured response-content analysis, weighted heuristic scoring, and hard-negative discrimination. The project presents a modular asynchronous scanning architecture designed for category-aware heuristic analysis across multiple vulnerability classes.

Key Features

  • Asynchronous scanning architecture
  • Category-aware heuristic detection
  • Structured response-content analysis
  • Payload testing framework
  • Weighted scoring mechanisms
  • Modular pipeline orchestration
  • Structured JSON reporting
